# DIEC Gestión

Aplicación web ligera y adaptable a móviles para acceder al espacio de trabajo de DIEC.

## Uso

Abre `index.html` en un navegador y selecciona un nombre para iniciar sesión. La sesión se conserva en el almacenamiento local de ese navegador hasta que se selecciona **Cerrar sesión**.

No se requiere instalación de dependencias ni un servidor de desarrollo. Para publicar la app, sirve estos archivos estáticos desde un hosting web.

## Nota sobre el acceso

El acceso por selección de nombre es una identificación local y no verifica la identidad de la persona. Como la sesión se conserva en el navegador, cualquier persona con acceso al mismo perfil del dispositivo podrá usar la sesión iniciada. No debe utilizarse como control de acceso para datos sensibles.
